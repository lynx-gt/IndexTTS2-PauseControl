# PAUSE_CONTROL 精确停顿控制方案

IndexTTS2-PauseControl 的 `[pause:N]` 实现方案与实验记录。

## 1. 方案总览（两代）

| | token 级（研究版，已弃用） | 全波形（生产版，当前） |
|---|---|---|
| 原理 | 在 LLM 语义码层面注入"静音码" | 生成后对波形静音核心做延长/缩短/插入 |
| 定位 | 码映射（有 2~13% 偏差） | 能量检测（物理信号） |
| 重解码 | 需要（改码后重跑 GPT→cfm→BigVGAN） | 不需要（免重解码） |
| 稳定性 | 上下文相关，部分位置出杂音 | 静音接静音，稳定 |
| 精度 | ±40~100ms | 实测 ±13ms 平均 |

弃用原因（token 级）：LLM 语义码中不存在可生成的"静音码"；实验提取的真静音码
CORE10 在部分上下文解码会出杂音（prod_01 实测"深/吸"之间插入杂音）——
详见下文第 3 节研究记录。代码保留在 `indextts/utils/pause_control.py` 供参考。

## 2. 全波形方案（生产）

### 2.1 核心思想（为什么"生成后修正"能精确控制）

IndexTTS2 的自回归生成是**逐 token 采样**的——同一个词每次生成的停顿时长
天然有 ±30% 波动（标点停顿统计 CV 0.31~0.56）。因此**不能指望模型"生成出"
精确时长**，本方案采用"两遍"思想：

> **让模型生成"有停顿"（定性），再用波形修正"停顿多长"（定量）。**

- 第一遍：`[pause:N]` → 逗号，模型按标点习惯自然生成停顿（**定性保证**——
  标点驱动停顿是模型的稳定行为，停顿率 95%+）
- 第二遍：在波形上检测停顿位置，把静音核心延长/缩短到目标时长（**定量修正**——
  波形域操作精度 ±30ms 以内）

关键洞察：**停顿的"位置"由文本标点决定（可靠），停顿的"时长"由模型采样决定
（不可靠）**。所以方案只依赖"位置"信息（能量检测物理信号），不依赖模型对
时长的任何预测——这就是它比"让模型直接生成目标时长"稳定的根本原因。

### 2.2 处理流程

```
文本（含 [pause:N] 标记）
  → parse_pause_marks：标记→逗号，记录字符位置与目标时长
  → 模型正常生成（一次，diffusion_steps 步）
  → detect_pauses：能量检测停顿段（宽松阈值找段 + 严格阈值找核心区）
  → nw_align：Needleman-Wunsch（仿射 gap + 不对称定价 + 时间硬上限）全局对齐标记↔停顿
  → 波形操作（按目标位置从后往前执行，避免坐标漂移）：
      目标 ≥ 自然时长 → wav_extend_pause（静音核心中部插静音）
      目标 < 自然时长 → wav_shrink_pause（静音核心裁剪，两端留 margin）
      漏停（NW 判定插入）→ 能量谷 + 真静音保护后插入
  → 输出
```

### 2.3 各环节原理

#### 2.3.1 标记解析（parse_pause_marks）

`[pause:N]` → **全角中文逗号（，）**（中英文文本统一替换，实测英文场景同样精确）。选择逗号的原因：
- 逗号在模型切段列表之外（模型内部只按句号/问号/感叹号切段）→ 标记不会导致
  文本被切成新段，停顿归属稳定
- 逗号驱动的停顿短（~310ms 中位）且存在率高（95%+），是"可修正"的起点
- 标记位置 = clean 文本中的字符偏移，供后续"预期位置"计算

#### 2.3.2 停顿检测（detect_pauses）

帧能量：`E = Σ x² / N`（10ms 帧，x 为样本），阈值 `(100/32768)² ≈ -50dBFS`。

**双层阈值设计**——这是"不切字"的关键：
- **宽松阈值（-50dBFS）**：找"停顿段"（含弱尾音），回答"哪里停过"
- **严格阈值（×5）**：找"静音核心区"（纯静音），回答"哪里能安全操作"

为什么需要区分：字的**弱尾音**（鼻音收尾、气声）能量低于宽松阈值但高于严格
阈值——它们属于语音，直接按宽松段裁剪会切字（实测"也"被切、"分"尾被切）。
操作只允许发生在严格核心区内部（两端再留 margin）。

#### 2.3.3 NW 对齐（nw_align）

问题：模型可能多停（句中气口被检成停顿）或少停（标点处没停），标记与停顿
数量不一致、位置有映射误差（字符比例映射 ±0.4s）——需要**全局最优匹配**。

**特征**（每个标记/停顿映射为 2 维向量）：
```
时间特征 t = 位置秒 / 音频总秒      （归一化到 [0,1]）
时长特征 d = 时长ms / 2000         （归一化，2000ms 为量程）
```

**匹配代价**：
```
cost(i,j) = |Δt| + w_dur × |Δd|     （w_dur = 0.2）
```

- **时间特征主导**（w_dur=0.2）：标记与停顿的位置对应是强信号。原始 w_dur=1.0
  时，若某处自然停顿时长"巧合"接近另一标记的目标时长，NW 会牺牲时间匹配换
  时长匹配（实测 18 段：目标 750ms 错配到自然 778ms 的停顿，正确停顿 229ms
  反被跳过）——参数扫描确认 0.05~0.5 全区间稳定
- **时间硬上限**（max_t_diff=0.8s）：候选对时间差超限直接禁止匹配（代价 INF），
  只能走插入/跳过——与权重正交的硬保险（实测错配时间差 0.93s 被硬性排除）

**gap 定价（不对称）**：
```
跳过标记（模型漏停 → 需要插入处理）：open 0.30 / extend 0.25  ← 贵，近线性
跳过停顿（模型多停 → 不动即可）   ：open 0.05 / extend 0.01  ← 便宜
```
不对称的原因：漏停必须"认真处理"（要补停顿），多停"放着不管"就行。若两者
同价，NW 会倾向用"跳过标记"逃避匹配（prod_01 实测教训）。

**置信度**：匹配距离 > 0.25 列入人工确认清单（可选输出）。

#### 2.3.4 波形操作（wav_extend / wav_shrink / insert）

只操作**静音核心区**，不碰任何语音样本——这是"无感"的基础：

- **延长**：在核心区中点插入纯零样本（静音接静音，无拼接痕迹）。
  `add = 目标 - 核心时长`，不足 15ms 不动（避免无意义抖动）
- **缩短**：保留核心开头 `目标-15ms` + 结尾 15ms，删除中间——裁剪后停顿
  = 目标时长，两端 margin 吸收 wav→样本边界误差
- **插入**（模型漏停）：在预期位置 ±100ms 窗口找帧能量最低点（能量谷），
  且能量必须 < 严格阈值（真静音）才插入；否则放弃（宁缺毋滥——插在语音
  中间会切字）
- **执行顺序从后往前**：延长/插入会改变该点之后所有样本的时间坐标，若按
  文本顺序执行，后面的操作会用旧坐标作用到错误位置（实测 13 段：延长
  611ms 后缩短操作用旧坐标产生伪停顿）——按位置降序执行则每个操作执行时
  其目标位置尚未被移动

**为什么免重解码**：操作发生在波形域（生成完成之后），不修改 codes、不
重跑 GPT/cfm/BigVGAN——比 token 级方案（改码→重解码）快一个数量级，且
不存在"重解码引入新伪影"的风险。

### 2.4 关键参数（实测标定）

| 参数 | 值 | 说明 |
|---|---|---|
| 检测帧长 | 10ms | 能量检测帧 |
| 检测阈值 | (100/32768)² | ≈ -50dBFS |
| 严格核心阈值 | 阈值×5 | 核心区 = 可安全操作的纯静音（弱尾音是语音，不能动） |
| NW gapA（跳过标记=漏停） | open 0.30 / extend 0.25 | 近线性——每个漏停都要认真处理 |
| NW gapB（跳过停顿=多停） | open 0.05 / extend 0.01 | 多停不动，几乎免费 |
| **时长特征权重 w_dur** | **0.2** | 时间位置主导匹配（见 §2.3.3） |
| **时间硬上限 max_t_diff** | **0.8s** | 候选对时间差超限禁止匹配（见 §2.3.3） |
| 缩短 margin | 15ms | 核心两端缓冲，防切字 |
| 插入保护 | 能量谷 < 阈值×5 | 无真静音拒绝插入（宁缺毋滥） |
| 操作顺序 | 按位置从后往前 | 防先延长/插入移动后续停顿坐标 |

### 2.3 修过的三个 bug（实测驱动）

1. **NW 时长权重错配**（prod20_18 实测）：标记0 目标 750ms，模型自然停顿 778ms 恰在
   非对应位置——w_dur=1.0 时 NW 牺牲时间匹配换时长匹配，导致"该长停处 229ms、该短停处
   750ms"互换。参数扫描（20 段自然停顿 ×7 权重）确认 0.05~0.5 全区间稳定、w=1.0 有
   5/20 段错配 → 定 w_dur=0.2。
2. **坐标漂移**（prod20_13 实测）：延长 611ms 后，后续缩短操作仍用旧坐标 → 作用到错误
   位置产生伪停顿 → 改为按位置从后往前执行所有操作。
3. **时间硬上限**：与权重正交的硬保险，0.93s 级错配被硬性排除；正确匹配时间差实测最大
   0.37s（0.8s 有 2.2 倍裕度）。

### 2.4 精度数据

- 验收：20 段真实语句 × 每段 1 延长(700~900ms) + 1 缩短(150~250ms)，共 40 个标记
  - **40/40 命中，平均 |偏差| 13ms，最大 32ms**
  - 延长全 -2~-32ms；缩短全 -30~+19ms
  - 含 1 个"插入"场景（900ms 目标 → 888ms）
- 跨音色验证：静音核心操作与音色无关（波形域，不涉及 embedding）

## 3. token 级研究记录（历史，供官方/社区参考）

### 3.1 核心发现

1. **LLM 语义码中没有"静音 token"**：v1 遗留的 52 号 token 未在生成路径调用。
2. **全零输入过编码器 = 呼吸码**（解码出 -49~-33dBFS 呼吸声），不是静音。
3. **真静音码存在**：从"模型自产停顿段"音频用 w2v-bert+RepCodec 编码得到
   `CORE10 = [5982, 5776, 215, 1327, 1004, 661, 7705, 879, 230, 2098]`
   （10 码核心，去头尾过渡码；跨音色注入解码干净，内部 maxRMS 23~77 = 解码器底噪）。
4. **每码 ≈ 20.3ms**（7 组 M 实测拟合：时长 = 20.3×M + 18.4ms）。
5. CORE10 循环 ×1~×7（100ms~1.4s）全部干净，×8 起杂音（码序列超限）。

### 3.2 码表研究结论（已查尽）

- LLM 停顿码 ≠ CORE10（不同码空间）
- mel_embedding 不可分（无停顿特征可分离）
- 78 个停顿专用码（统计倾向），但分散/缺失，无法可靠定位 → **token 级静音核心定位
  无可靠判据**
- 注意力定位（GPT2Attention）：24 层全 None 是 `_attn_implementation="sdpa"` 下
  SDPA 不返回权重；切 eager 后可得权重，但假阳性/假阴性结构性存在（气声/齿音/长停顿
  拆段），信号不携带"停顿 vs 气声"判别信息 → 判定不可靠，封存。

### 3.3 弃用结论

token 级方案在生产中不可靠（上下文相关杂音、短停顿切字/膨胀、定位无判据），
**全波形方案定版**。token 级代码与实验记录保留供官方改进码空间时参考。

## 4. 检测步数差距（10 vs 25 步）

| 指标 | 10 步 | 25 步 |
|---|---|---|
| 停顿起点偏差（中位） | 基准 | +20ms |
| 停顿时长偏差（中位） | 基准 | -10ms |
| 伪影停顿（多检） | ~20% 句子多 1 个 | 0 |
| 速度 | 2.23× | 1× |

检测用 10 步可显著加速，NW 对齐可容忍上述偏差；生产默认 25 步（准确优先），
如追求速度可自行把检测步数调为 10（全波形版检测与输出共用一次生成，此参数已无独立作用）。

## 5. 已知限制（实测）

1. **长停顿后模型自带换气**：停顿（精确命中）之后模型可能吸气（呼吸声，能量高于静音
   阈值），检测/工具不触碰——属模型自然韵律，需去除请用后处理降噪。
2. **插入需要真静音**：目标位置语音连续（无能量谷）时拒绝插入，宁缺毋滥。
3. **字符比例映射误差**：标记预期位置 = 字符比例 × 音频时长，长句误差可达 ±0.4s；
   NW 对齐 + 时间硬上限兜底。
4. **短停顿测量口径**：<250ms 停顿的验收测量含弱尾音，偏差略大（±30ms 内），听感正常。
