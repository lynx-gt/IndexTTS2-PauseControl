# 打补丁说明（给已有官方 indextts 包的用户）

本目录面向**已经拥有官方 IndexTTS2 推理代码**的用户（官方整合包、官方 ComfyUI 节点、
或自建推理管线）。只需应用这里的修改即可获得 `[pause:N]` 精确停顿能力，
无需整套拷贝。

## 修改文件清单

| 文件 | 操作 | 内容 |
|------|------|------|
| `modified/transformers_generation_utils.py` | **覆盖** `indextts/gpt/` 下同名文件 | transformers 4.57 兼容补丁 3 处 |
| `modified/transformers_gpt2.py` | **覆盖** `indextts/gpt/` 下同名文件 | transformers 4.57 兼容补丁 2 处 |
| `modified/infer_v2.py` | **覆盖** 你的 `indextts/infer_v2.py` | seed 支持 + soundfile 输出 + **pause_mode 全波形分支** |
| `新增文件/pause_control.py` | **复制** 到 `indextts/utils/` | 停顿解析/检测/NW 对齐/波形操作核心 |

> ⚠️ `infer_v2.py` 是本项目修改后的完整版，直接覆盖会**替换你对该文件的本地修改**。
> 如果你已在官方 infer_v2.py 上做过自定义，请对照 `docs/PAUSE_CONTROL.md` 第 6 节
> 与下方功能说明手动合并。

`infer_v2.py` 相对官方的功能改动：
1. `seed` 参数：固定 seed 可复现（写 `<输出>.seed` 文件）
2. 输出改用 soundfile 写 wav（torchaudio 2.9 在 Windows 不可用）
3. `pause_mode=True` 时：文本中 `[pause:N]` 标记 → 逗号生成 → 检测 → NW 对齐 → 波形操作

## 启用方式

**WebUI（Gradio）用户**——调用推理时传入参数：

```python
tts.infer(
    spk_audio_prompt=ref_path,
    text="他停下脚步[pause:800ms]深吸一口气[pause:200ms]然后推开了那扇门。",
    output_path="out.wav",
    pause_mode=True,   # ← 新增参数
)
```

在 webui.py 的生成函数里给 `infer()` 加一行 `pause_mode=True`（或检测文本含
`[pause:` 时自动开启）即可。

> ⚠️ **声明**：WebUI 接入方式已按上述接口实现，但**未经实际部署使用验证**——
> 本项目生产环境为 ComfyUI。如有问题请提 issue。

## 快速自检

```python
from indextts.infer_v2 import IndexTTS2
tts = IndexTTS2(cfg_path=".../config.yaml", model_dir="...", use_fp16=False)
tts.infer(spk_audio_prompt="ref.wav",
          text="他停下来[pause:900ms]深吸一口气。",
          output_path="test.wav", pause_mode=True)
# 预期："停下来"后停顿 ≈ 900ms
```
